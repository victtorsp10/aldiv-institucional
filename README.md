# Projeto Vite + React + shadcn-ui

Este repositório contém um template Vite + React com TypeScript e integração com shadcn-ui e Tailwind CSS.

Como rodar localmente:

```powershell
npm install
npm run dev
```

Tecnologias usadas:

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

Para dúvidas ou ajustes, atualize este README com informações do seu projeto.
